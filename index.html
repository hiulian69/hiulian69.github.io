02. Selected work

csvprofile

Python CLI · tested & shipped

Before analysing a new CSV you need to know what's actually in it: which columns have gaps, which ones are really IDs, and where text has crept into a number column. Usually that means retyping the same df.info() and value_counts() calls in a notebook every time. csvprofile runs the whole per-column check in one command and lists the problems it finds underneath the table.

Customer Segmentation with K-Means

Machine learning · 3 real datasets
